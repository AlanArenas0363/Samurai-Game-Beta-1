# Samurai Game made with Phaser

This is a digitilization of the first level that I made physically. This level is about one samurai that is fighting to another samurais that are against him. The place that takes this first level is in a Japanese Neighborhood. 

## How to play this game.

- Download the "game.html" file.
- Open the file with the web browser of your preference.
- The game will begin automatically.

## Controlls.
- D, A, Right arrow or Left arrow to move forward or backwards.
- Space or W to jump.
- E to interact
- R to respawn or reload game.

## Goal of the game.
Collect the most of Yens that you can by killing the enemies, don't lose all your lives or you have to start over again.
